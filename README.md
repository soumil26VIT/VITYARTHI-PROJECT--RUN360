# VITYARTHI-PROJECT--RUN360
Overview:-RUN 360 is a Python-based smart attendance and management system designed to manage student and industrial activities through a single platform.The project provides two modes:
Student Mode  – for managing attendance, tasks, events, marks, and timetable ; Industrial Mode – for managing employee attendance, shifts, check-in/check-out, working hours, and work tasks. The main aim of RUN 360 is to reduce manual record keeping and provide a simple, organized system for managing important daily information. The project is developed using basic Python programming concepts such as variables, conditional statements, loops, functions, lists, dictionaries, file handling, and data processing.

Features of the project:- 
Student Mode:
- Student registration and login
- Student attendance marking
- Present/Absent status
- Attendance report
- Attendance percentage calculation
- Task and assignment management
- Task completion tracking
- Event management
- Marks management
- Timetable management
- Persistent data storage
 Industrial Mode
- Employee registration and login
- Employee shift management
- Check-in
- Check-out
- Working-hour calculation
- Employee attendance records
- Attendance reports
- Work-task management
- Persistent employee data
 Data Management
- JSON files for application data
- CSV file for attendance records
- Automatic creation of required data files
- Data remains available after restarting the program

Technologies / Tools Used :-
Python 3 :-Main programming language 
JSON :-Storage of students, employees, tasks, events, marks, and timetable |
CSV :- Storage of attendance records 
Raptor :-Algorithm and flowchart design |
For Code execution:- VS Code / PyCharm / IDLE 
GitHub :-Project repository and submission
